# homebrew-tap

Homebrew tap for monkescience projects.

Works on macOS and Linux (via [Homebrew on Linux](https://docs.brew.sh/Homebrew-on-Linux)).

## Usage

The shortest form — auto-taps on first use:

```sh
brew install monkescience/tap/<cask>
```

Or tap once, then install by name:

```sh
brew tap monkescience/tap
brew install --cask <cask>
```

## Available Casks

| Cask | Description |
|------|-------------|
| [yeet](https://github.com/monkescience/yeet) | Automate releases based on conventional commits |
